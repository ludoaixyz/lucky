# Responsible design

LUCKY888 currently permits simulated credits only. Credits cannot be bought, sold, withdrawn, transferred, redeemed, or expressed as cash or cryptocurrency. The repository excludes real-money wagering, deposits, withdrawals, payment systems, gambling accounts, misleading win/RTP claims, autoplay, rapid spin, loss-chasing prompts, and manipulative loss-recovery or retention mechanics.

Numerical scaffolding must be labeled provisional. Any proposal that changes these constraints requires explicit product, legal, security, and responsible-design review outside this prototype; it must not be slipped into an ordinary implementation change.

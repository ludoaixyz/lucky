# Game design overview

The initial loop is deliberately small: the player sees five reels by three rows, spends a fixed five simulated credits, receives a pre-resolved result, watches a short reveal, and sees updated credits and latest win. Mouse click and Space are supported; input locks during presentation.

The letters, gem, wild, scatter, five paylines, reel strips, awards, feature trigger, colors, sounds, pacing, and starting balance are provisional engineering fixtures. Free-spin configuration is representable but the shell does not yet run a free-spin feature. There is no autoplay, rapid spin, purchasing, cash value, account, or loss-recovery messaging.
